# React Movie App

A modern movie browsing web app built with React, Vite, TMDB API, and Appwrite.

---

## Features

- Search movies (real-time with debounce)
- Movie details page
- Trending movies (tracked with Appwrite)
- Favorites (local storage)
- Authentication (Appwrite login/register)
- Fast UI with Vite
- Clean modern UI design

---

## Tech Stack

- React (Vite)
- Appwrite (Database + Auth)
- TMDB API
- React Router
- CSS (custom styling)

---
